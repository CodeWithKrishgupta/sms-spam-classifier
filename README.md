# 📩 SMS Spam Classifier

A Machine Learning-based web application that classifies SMS messages as Spam or Not Spam.

---

## 🚀 Features
- Real-time spam detection
- Simple web interface
- Fast prediction using trained model

---

## 🛠️ Tech Stack
- Python
- Flask
- HTML, CSS
- Machine Learning (NLP)

---

## 📂 Files
- app.py → Main backend
- model.pkl → Trained model
- vectorizer.pk → Text vectorizer
- index.html → Frontend UI
- SMS Spam Classifier.ipynb → Model training
- Book1.csv → Dataset

---

## ▶️ Run Project
1. Install libraries  
   pip install flask sklearn pandas  

2. Run app  
   python app.py  

3. Open browser  
   http://127.0.0.1:5000/
